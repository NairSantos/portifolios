Pokémon Art Portfolio

Este projeto é uma página simples criada com TypeScript, servindo como exemplo de portfólio. Nesta versão, utilizei uma pasta local para organizar e exibir as imagens e GIFs diretamente do próprio servidor. É uma forma prática e acessível de mostrar artes sem depender de banco de dados ou serviços externos. A galeria traz uma seleção de ilustrações que fiz inspiradas no universo Pokémon — essa é uma versão alternativa pensada com carinho pra quem curte algo mais direto e leve. ✨🎨🖼️
