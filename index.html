Portfolio

Este projeto é uma página simples criada com TypeScript, servindo como exemplo de portfólio.
Utilizei o Firebase para armazenar e organizar tudo, permitindo que as imagens e GIFs sejam carregados diretamente do banco de dados na nuvem. Tem um ilustrativo que eu fiz com meus desenhos do pokemon la primeira branch mas é apenas para visualização, essa é uma versão alternativa pensando em você. ✨🛠️
